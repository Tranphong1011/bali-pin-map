Google images (optional)

By default the app fetches 3 free photos from Wikimedia Commons (by place name + location), plus a button to open Google Images for more. To have the app pull photos directly from Google, you need a Google Custom Search JSON API key + a Search engine ID (cx) with “Image search” enabled.

Note: Google no longer issues this API to new customers — only fill this in if you already have a key. The key is stored only in your browser.
